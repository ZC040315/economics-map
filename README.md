## 本地运行

```bash
npm run dev
```

打开 http://localhost:5173 。

## 页面结构（Hash 路由）

- `#/` 首页：定位 + 进度 + 薄弱点 + 快捷入口
- `#/map` 知识地图：SVG 节点图（缩放/平移/状态色/跳转）+ 树形辅助
- `#/chapter/:id` 章节页：视频 + 回忆卡 + 分层题库
- `#/knowledge/:id` 知识点页：一句话理解/核心概念/图形/公式/重点/易错/相关知识
- `#/review` 复习页：待复习队列 + 薄弱章节
- `#/skills` 现实能力：能力地图 + 场景卡 + 决策工具
- `#/skills` 反击擂台：先写「对手会怎么反击我」再揭晓经济学反方观点

支持 Dark Mode（跟随系统 + 手动切换）、全局搜索（章节/知识点/公式/题目）、
Desktop / Tablet / Mobile 响应式布局。

## 目录结构

```
src/
  data/       # 章节数据、回忆卡（7 章 41 张）、视频库（≤20 分钟）、题库（7 章 × 17 题）、场景库（30 张）
  lib/        # 进度保存与掌握度计算等纯函数工具
  components/ # Header / 地图树 / 章节详情 / 占位卡
  styles/     # 设计令牌与全局、组件样式
```
