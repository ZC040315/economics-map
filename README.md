## 本地运行

```bash
npm run dev
```

打开 http://localhost:5173 。

## 测试与构建

```bash
npm test
npm run build
```

## 部署

仓库内置 GitHub Pages 自动部署工作流：推送到 `main` 分支后，
GitHub Actions 会自动构建并发布到
`https://ZC040315.github.io/economics-map/`。

## 目录结构

```
src/
  data/       # 章节数据、回忆卡内容（7 章 41 张）、视频库（每章 1 主 + 2 备用）
  lib/        # 进度保存与掌握度计算等纯函数工具
  components/ # Header / 地图树 / 章节详情 / 占位卡
  styles/     # 设计令牌与全局、组件样式
```
